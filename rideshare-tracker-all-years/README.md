# Uber Earnings Tracker

Static personal rideshare tracker for all dates and all years.

## Features

- Reports: daily, weekly, monthly, yearly rollups
- Log: save one day by date
- Entries: view saved days
- Backup: export JSON, export CSV, import JSON backup

Data is stored in your browser with `localStorage`. Use the backup screen regularly if you use GitHub Pages.

## GitHub Pages

Upload these files to your repository:

- `index.html`
- `styles.css`
- `app.js`
- `README.md`

Then enable GitHub Pages from repository settings.
